## How I Test Performance

I made my own **lag tester** to compare the engines.

The test works by:

* Setting the scroll speed to **2.5×**
* Continuously increasing the number of notes
* Making the notes progressively denser
* Watching for when the engine begins to experience noticeable lag

The purpose of this test is to see how much note density each engine can handle before performance starts dropping.

The results are specific to **my testing setup and methodology**, so they shouldn't be treated as a universal measurement of engine performance.
